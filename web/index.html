这个 MVP 是什么

      
一句话纠错：中文学习者写完一句话，不知道说得对不对、怎样更自然。AI 只指出一个最主要的问题，
      给出更自然的表达和简短解释。

      
刻意不做的功能：语音识别、实时对话、课程体系、用户系统。先把一个点做透、测透。

    


    

      
为什么 Key 不写进代码

      
这个页面未来会部署到 GitHub Pages 公开访问。任何写进前端代码的 Key 都会被任何人看到并盗刷。
      因此 Key 只存在使用者自己的浏览器里，代码仓库中不含任何密钥。

      
如果将来要公开发布让别人免 Key 体验，正确做法是加一层服务端代理（如 Cloudflare Worker）
      把 Key 挡在后端。这一步留到后续迭代。

切换模型服务

        
在「练习」页顶部的「模型服务」卡片里选服务商，或直接用自定义填中转站地址。
        三项必填：Base URL、模型名称、API Key。

        
    
          
  • 中转站 / 自建网关（One API、New API 等）：选「自定义」，Base URL 填到 /v1 为止，
              模型名按该网关的规范填
    • 
          
  • 地址怕填错？填的时候下方会实时显示拼好的完整请求地址，对着检查一遍
    • 
          
  • 拿不准能不能用？点「测试连接」，会发一个 1 token 的最小请求，直接告诉你通不通、实际命中的是哪个模型
    • 
          
  • 报 response_format 相关错误？取消勾选「严格 JSON 输出」再试，程序也会自动降级重试一次
    • 
        

        
各家地址以官方文档为准，预设值如有变动直接在输入框里改即可。

      


      

        
场景页怎么玩

        
每一局由 场景 + 对手性格 + 本局挑战 + 意外事件 四张牌随机组成，点「🎲 换一批」重抽。
        开局后 AI 会现场编写这一局的剧本（开场白、4 轮任务、意外的台词），所以同一个场景再玩一次也不一样。

        
    
          
  • 素材池：18 场景 × 10 性格 × 9 挑战 × 14 意外，组合数 45,360
    • 
          
  • 意外事件会在第 2 或第 3 轮突然插入，角色会把那句话说出口，你得临场应对
    • 
          
  • 只是重复原来那句话不算化解，要能处理新情况才算过——这一点写进了判断提示词
    • 
          
  • AI 编的剧本要过结构校验，不合格就回落本地模板，并在页面上如实标明来源
    •
